Media placement guidance

- Put hero video: `/public/videos/dsf-hero.mp4`
- Put hero poster: `/public/posters/hero.jpg`
- Additional images: `/public/images/*`

Video formats supported: MP4 and WebM. Poster images are recommended as 1920x1080 JPG or optimized WebP.

If the video isn't present the site will gracefully show a sophisticated placeholder.
